07 / behavior

A few patterns
with a pulse.

Native disclosure and dialog semantics do the heavy lifting. The toast is a small local confirmation, not a live notification feed.

native accordion

Make room for context.

What is this library for?+

It is a portable set of named classes for the Cozy Clay direction. Keep the tokens shared, then adapt the material to the content.

What belongs in a project card?+

A clear title, a human description, one status badge, and one next action. Stats should be labeled sample data when they are illustrative.
