## Proposed changes
- New `backend/crowd_set` package and standalone FastAPI app on loopback port 8010. Dedicated frontend API base defaults to loopback 8010, with no production fallback. Existing shared backend/routes and sandbox guards stay untouched.
- JSON metadata and generated UUID paths under ignored `.crowd-set/`. Atomic metadata replacement and a process lock enforce a single local server. Workers inherit the storage flock and enforce their own 15-minute process-group deadline, so a parent crash cannot release ownership while a worker writes. Restart refuses while an old worker is alive; once it exits, interrupted processing/upload state is marked failed. A bounded single worker runs CPU/media work outside HTTP handlers; jobs execute in a child Python process with a wall-clock deadline.
- Raw streaming upload endpoint avoids multipart spooling before limits. Extension allowlist, byte limits, file count, total disk budget, duration limits, safe opaque paths, ffmpeg protocol/demuxer restrictions, subprocess argument arrays, decoder deadlines, and local Host/Origin checks bound untrusted inputs. The optional imageio-ffmpeg package supplies ffmpeg; ffprobe is not required.
- Decode reference to 16 kHz mono float32 analysis WAV; crowd to 32 kHz mono float32 working WAV, deriving 16 kHz analysis. Preserve decoder/downmix peaks above full scale until gained final PCM output. Memory-map working samples and process bounded slices. Reserve 3 GiB for generated audio during upload admission. Conversion adds no enhancement. A later rendering step applies measured constant gains. Analyze 24 log-frequency energy-change bands at 25 Hz. Correlate several independent windows against full reference, require similarity/peak separation and offset consensus, and abstain on conflicting timing. Scores remain heuristic. Long files sample multiple locations; no drift correction.
- Assembly receives only matched, enabled crowd sources. Greedy farthest-end coverage selection minimizes switches. Piecewise timeline includes explicit gaps, with <=80 ms linear fades inside actual overlap. Render bounded blocks to PCM WAV, preserving reference duration and silence in gaps.
- Basic level matching measures integrated BS.1770 loudness and true peak on validated working WAVs with ffmpeg loudnorm analysis only (output discarded). The first selected clip anchors at -23 LUFS; subsequent sources compare the last up-to-30 seconds of actual common coverage when >=8 seconds overlap, otherwise use a disclosed whole-clip -23 LUFS fallback. Clamp provisional gain to [-60, +12] dB, then apply common attenuation to reserve 2 dB true-peak headroom. Render only constant gain per source and linear overlap fades. Measure final output peak, and if necessary rerender with additional common attenuation. No limiter, compressor, denoiser, EQ, or acoustic improvement claim.
- React page: create/select sets, role-based upload, inclusion controls, processing polling, matched/unmatched rows, coverage, gaps, native playback and download. Local-only link from Commons navigation.
- Optional dependencies in `backend/requirements-crowd-set.txt`; portable Bash launcher creates its own virtualenv and binds 127.0.0.1. No changes to existing deployment image or Supabase.

## Hosted test adaptation

Route the exact prefix on the existing HTTPS origin; retain the other applications and sandbox guards. Use a persistent `/data` volume, 2 CPU/2 GiB cap, one replica and manual deployments. Host/origin enforcement and validated Supabase Auth identity are required in hosted mode; all set operations enforce metadata ownership. The only Supabase operation is user-token validation via Auth; no database key or table access is needed. Secure scoped cookies support native audio range/download requests; bearer tokens remain mandatory for mutations.
